# Exercise and timer sources

The app uses the supplied files as its exercise sources. A timer window is not an original prescription unless explicitly identified as one. Original mobility routine objects remain unchanged.

| App content | Supplied source | What is retained / adapted |
| --- | --- | --- |
| Wrist rocks (forward, backward, side), Palm Peel Aways | Mobility Toolkit Week 1 Day 1b image and existing app cues | 10 reps; direction names follow the existing app. Warm-up set volume and countdown windows are adaptations. |
| Wrist Flexor Opener, Wrist Extensor Opener, Finger Stretch, Scap Push-Up | HomeHero_eBook_2020.pdf, page 6 | Exercise names and 10 reps. Warm-up timers are app pacing estimates. No unnamed wrist movements are added. |
| Easy assisted pulls, pike presses, lean planche push-ups | Petar Cycle 1 and Cycle 2 upper-body sheets | Easy primers use these existing strength movements. Primer sets/reps and setup time are adaptations within the seven-minute preparation block. |
| Assisted OAC | Petar Cycle 2, Upper Body Workout II, a1 and G10 comment | Weaker arm first, three reps per arm, 30 seconds between arms, controlled lifting/lowering. Main-pair rest is adapted to 120 seconds. |
| OAC negatives | Petar Cycle 2, Upper Body Workout I, a1 comment | Five seconds of descent plus a three-second hold at the weak point, and 30 seconds between arms. Setup window is estimated; the user chooses the weak point. |
| Pike HSPU | Petar Cycle 1 b1/a2 and Cycle 2 b1, including comments | Controlled lowering and pressing; elevated-feet setup and keeping hip alignment. MED set volume is an adaptation. |
| Lean planche push-up | Petar Cycles 1–2, d1 and comments | Maintain lean and hip/shoulder alignment; original 1/1/3/0 tempo is named by phase. Set volume and paired rest are adaptations. |
| Supinated ring row | Petar Cycle 1 Workout II, b1 comment | Supinated grip and progressively more horizontal position; source tempo retained. |
| Face pull | Petar Cycle 2 e1; Cycle 2 Remake c2; Cycle 3 f1/c1 | Controlled three-second pulling/return phases and the slow-tempo cue. MED volume is adapted. |
| Handstand control | Home Hero pages 17 and 28; existing app balance cues | Wall alignment and core cues; five 30-second attempts selected within the source's 3–5 sets of 30–60 seconds. Balance practice and 30-second rests are adaptations for the five-minute block. |
| Bar muscle-up foundations | Existing app muscle-up work and user's explicit bar muscle-up goal | Assisted high pulls, bar transitions and straight-bar dips are retained from the accepted app plan. They are explicitly app adaptations, not attributed to Petar's sheets. |
| Mobility holds, per-rep pauses and final-rep holds | Existing mobility routine data and supplied split/toolkit images | Reps, sets and holds are unchanged. Timers distinguish a hold each rep from a hold only on the last rep. |
| Shoulder Protocol | Toolkit Day 2/Day 4 images and existing app | Source says 20 reps per move but does not name each move in the screenshot. Keep the protocol intact; do not invent its sub-exercises. A 120-second guided window is an app estimate. |

Petar's Cycle 2 Remake and Cycle 3 were reviewed as supporting resources. Their hypertrophy emphasis does not replace the user's requested Big 4 focus. Home Hero's 2–3-workouts-per-week recommendation is not adopted because the user requested one complete weekly primary session.
